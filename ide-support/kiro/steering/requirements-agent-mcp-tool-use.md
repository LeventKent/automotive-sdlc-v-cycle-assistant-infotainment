When a JSON output has been detected from the automotive_requirements_analyzer MCP tool, examine the content.
If the output contains a requirements analysis summary, save it next to the respective requirements file.

If it contains a user acceptance test specification, extract and save it to the most appropriate location in the project structure. Look for existing user acceptance test files, user acceptance test directories, or create a new user acceptance test directory if needed. The user acceptance test should be saved with an appropriate filename related to the respective requirements specification.
